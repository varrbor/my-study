# The Fun Side of Cabling: Racks, Adapters and Tools
- Structured cabling: device → wall jack → horizontal cable → patch panel → switch
- Keeps permanent cabling fixed, changes are made with short patch cables

## Racks
- Standard width 19 inches, height measured in rack units (1U = 1.75 in / 44.45 mm)
- Full rack is usually 42U; open frame, enclosed cabinet or wall-mounted
- Patch panel: terminates permanent cable runs, ports are labelled
- Cable management: horizontal/vertical organizers, velcro ties, labels on both ends
- Also in the rack: switches, routers, servers, PDU (power), UPS (battery backup)
- Hot aisle / cold aisle layout for cooling

## Adapters and transceivers
- Transceiver (SFP 1G, SFP+ 10G, QSFP+ 40G, QSFP28 100G): pluggable module, picks the media per port
- GBIC: older, larger predecessor of SFP
- Media converter: joins copper to fibre
- DAC (direct attach copper): fixed cable with SFP ends for short in-rack links
- Coupler: joins two cables; keystone jack: snaps into a wall plate or panel
- Wiring standards T568A / T568B: same on both ends = straight-through, mixed = crossover

## Tools
- Crimper: attaches RJ45 connectors to cable
- Punch-down tool: seats wires into patch panels and keystone jacks
- Cable stripper / cutter: removes the outer jacket
- Cable tester: checks continuity, pinout, shorts and split pairs
- Certifier: verifies a run meets its category (Cat6, Cat6a) speed
- Tone generator and probe: traces one cable in a bundle
- Loopback plug: tests a port by sending its signal back
- TDR / OTDR: finds the distance to a break (copper / fibre)
- Light meter and visual fault locator: measure and spot fibre loss
