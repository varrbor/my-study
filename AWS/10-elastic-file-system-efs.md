# Elastic File System (EFS)

Amazon EFS is a fully managed, elastic NFS file system that can be mounted simultaneously by multiple EC2 instances across multiple Availability Zones. Unlike EBS (which attaches to one instance at a time), EFS supports shared access, making it ideal for content management, web serving, and applications needing a common file system across many servers. It automatically scales storage capacity up or down as files are added or removed, with no manual provisioning needed.
