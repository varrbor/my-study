# Hands On: Using Bedrock for Generative AI

Amazon Bedrock is a fully managed service that provides access to foundation models (large language and image generation models) from AWS and third-party providers (like Anthropic's Claude, Meta's Llama, and others) through a single API. It lets developers build generative AI applications—chatbots, summarization, content generation—without managing the underlying infrastructure, and includes tools for fine-tuning, grounding responses in your own data (RAG), and applying safety guardrails.
