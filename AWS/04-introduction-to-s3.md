# Introduction to S3 - Unlimited Object Storage in AWS

Amazon S3 (Simple Storage Service) is an object storage service that lets you store and retrieve any amount of data—files, images, backups, videos—from anywhere on the web. Data is organized into "buckets" (containers) holding "objects" (the files plus metadata), and each object is accessed via a unique key/URL. S3 is durable (designed for 99.999999999% durability), highly available, and scales automatically, making it a foundation for backups, static website hosting, and data lakes.
