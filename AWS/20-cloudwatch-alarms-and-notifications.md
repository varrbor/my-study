# CloudWatch - Create Alarms and Notifications

Amazon CloudWatch collects metrics, logs, and events from AWS resources for monitoring. CloudWatch Alarms watch a metric (e.g., CPU utilization, error rate) against a threshold and change state (OK, ALARM, INSUFFICIENT_DATA) when conditions are met, triggering actions like sending a notification via SNS, scaling an Auto Scaling Group, or stopping an instance. This enables proactive monitoring and automated responses to operational issues.
