# Introduction to DynamoDB - A Managed NoSQL Database

Amazon DynamoDB is a fully managed, serverless NoSQL key-value and document database known for consistent single-digit-millisecond performance at any scale. Instead of tables with fixed schemas and SQL joins, DynamoDB stores items (similar to JSON documents) organized by a primary key, and scales automatically to handle virtually unlimited throughput and storage. It's commonly used for applications needing fast, predictable performance like gaming, IoT, and real-time apps.
