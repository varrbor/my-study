# Introduction to RDS - Create Managed Databases (SQL, Oracle, and more)

Amazon RDS (Relational Database Service) is a managed service for running relational databases—MySQL, PostgreSQL, MariaDB, Oracle, SQL Server, and Amazon's own Aurora—without manually handling server provisioning, patching, backups, or replication setup. RDS automates routine database tasks like backups, software patching, and failover (via Multi-AZ deployments), letting you focus on schema design and queries instead of database administration.
