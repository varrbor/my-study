# Demo: Navigating the IAM Dashboard

IAM (Identity and Access Management) is the AWS service for controlling who can access what. The IAM dashboard lets you manage Users (individual identities), Groups (collections of users with shared permissions), Roles (temporary permission sets assumable by users, services, or applications), and Policies (JSON documents defining allowed/denied actions on specific resources). It's also where you view your account's security recommendations, like enabling MFA on the root account.
