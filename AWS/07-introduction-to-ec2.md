# Introduction to EC2 - Run Virtual Servers in AWS

Amazon EC2 (Elastic Compute Cloud) provides resizable virtual servers ("instances") in the cloud. You choose an instance type (CPU/memory/network profile), an Amazon Machine Image (AMI) as the OS/software template, storage, and networking settings, then launch and pay only for what you use (per-second/hour billing). EC2 is the core compute building block of AWS, used to run applications, websites, and backend services with full control over the operating system.
