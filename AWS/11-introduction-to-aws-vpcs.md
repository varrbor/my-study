# Introduction to AWS VPCs - Networking in the Cloud

A VPC (Virtual Private Cloud) is an isolated, customizable virtual network within AWS where you launch resources like EC2 instances. You define IP address ranges (CIDR blocks), subnets (public or private), route tables, and gateways to control how traffic flows in, out, and within your network. VPCs give you full control over network topology and security, similar to running your own private data center network, but in the cloud.
