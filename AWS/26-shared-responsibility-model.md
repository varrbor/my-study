# The Shared Responsibility Model - What are My Responsibilities?

AWS and the customer share security responsibilities: AWS is responsible for "security OF the cloud" (physical data centers, hardware, networking infrastructure, and the virtualization layer), while the customer is responsible for "security IN the cloud" (data encryption, access management/IAM, OS patching on EC2, network configuration, and application-level security). The exact split shifts depending on the service type—e.g., managed services like RDS shift more responsibility to AWS than unmanaged EC2 instances.
