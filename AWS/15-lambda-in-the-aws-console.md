# Lambda in the AWS Console

The Lambda console lets you create functions, choose a runtime (Node.js, Python, Java, etc.), write or upload code, configure triggers (like API Gateway, S3 events, or EventBridge schedules), and set resource limits (memory, timeout). It also provides a built-in test feature to invoke functions with sample input and view execution logs/results directly, making it easy to build and debug serverless functions without leaving the browser.
