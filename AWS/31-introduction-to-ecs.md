# Introduction to ECS - Run Containers in the AWS Cloud

Amazon ECS (Elastic Container Service) is a fully managed container orchestration service for running Docker containers at scale. You define "task definitions" (container specs) and run them as standalone tasks or long-running "services," on either EC2 instances you manage or AWS Fargate (serverless compute for containers, no servers to manage). ECS handles scheduling, scaling, and health monitoring of your containers.
