# Introduction to Serverless Using Lambda - Eliminate Virtual Servers!

AWS Lambda lets you run code without provisioning or managing servers—you upload a function, specify a trigger (e.g., an API call, file upload, schedule), and AWS runs it on demand, scaling automatically and charging only for actual execution time. This "serverless" model removes the need to manage infrastructure, patch OSes, or pay for idle capacity, making it ideal for event-driven workloads, APIs, and automation tasks.
